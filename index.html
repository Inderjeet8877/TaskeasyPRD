Commercial Workflow

Zero-Touch SaaS Provisioning

Transitioning from manual onboarding to an autonomous, high-margin commercial engine. Follow the exact user journey for a new agency purchasing the software.

1. Dynamic Seat Configurator

The agency Admin uses interactive counters to select exact licenses needed across Admin, Finance, and Agent roles. The system dynamically computes MRR and adds mandatory 18% GST.

2. Frictionless Payment Gateway

Integration with PCI-DSS compliant gateways (Razorpay/Stripe) supporting UPI, Credit/Debit, and Net Banking for seamless checkout conversion.

3. Automated Provisioning

Backend autonomously initializes a logically isolated MongoDB Atlas partition, generates requested user accounts, and creates high-entropy temporary passwords.

4. Credential Handover & Governance

A PDF Credential Roster is generated exclusively for the Admin. Crucial Security Step: The Admin must change their own password and manually reset all staff passwords before offline distribution.

Bounded Contexts

Core Platform Modules & Logic

The three pillars of TASKEZY, enforcing strict data hygiene and operational compliance across the organization.

📈

CRM: Sales Management

  • Meta OAuth 2.0: Frictionless, zero-touch Facebook/Instagram ad connection. No dev tools needed.
  • Deduplication: Strict 10-digit mobile number validation blocks duplicates.
  • DAG Workflow: Enforced pipeline progression (New ➔ Contacted ➔ Booked).
  • Terminal Rules: "Booked" status requires INR Deal Value & mandatory KYC document upload.
👥

HRMS: Workforce Telemetry

  • Geofenced Attendance: Capacitor-powered GPS capture on mobile Punch In/Out.
  • Auto-Auditing: Shifts under 4 hours autonomously flagged as "Half Day".
  • Regularization: Unapproved missed punches automatically calculate proportional salary deductions.
  • Offline Resiliency: WatermelonDB allows offline use in dead-zones, auto-syncing via CRDTs later.
💰

Finance Operations

  • Automated Drafts: A "Booked" CRM lead instantly creates a Draft Booking.
  • Verification Gates: Invoice generation is physically disabled until KYC docs are manually verified.
  • Autonomous Tax Engine: Auto-generates sequential IDs and calculates 18% GST (9% CGST + 9% SGST).
  • Overdue Alerts: Background tasks monitor due dates against balances to mutate unpaid statuses.

Architecture Overview

Database Showdown

Selecting the correct database is the most critical architectural decision for a multi-tenant SaaS. TASKEZY upgraded to MongoDB Atlas to secure predictable OpEx and handle complex analytical pipelines.

MongoDB Atlas (Selected)

Predictable instance-based compute costs, seamless polymorphic data handling for custom tenant fields, and immense aggregation power.

Firebase Firestore (Legacy)

Suffers from the "Pricing Trap" with variable pay-per-operation costs that become exorbitant at high scale. Poor aggregation capabilities.

PostgreSQL (Evaluated)

Unmatched ACID compliance, but the schema rigidity makes it extremely difficult to allow individual SaaS tenants to create custom data fields on the fly.
