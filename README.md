# Taskezy product requirements

The product requirements document for Taskezy, a SaaS platform for real estate teams, turned into a one-page infographic. It covers the product scope and how it is meant to be sold.

Live: https://taskeasy-prd.vercel.app

The page is a single `index.html` with no build step. Open it in a browser or serve the folder with any static server.

The source document, `Upgraded Product Requirements Document (PRD).docx`, is in the repo too.
